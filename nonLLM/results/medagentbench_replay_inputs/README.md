# Minimal replay audit inputs

Numeric outcomes/costs, frozen risk scores and anonymous split-group labels only. No task views, answers, actual patient identifiers, demographics or medical records. Original table hashes and official dataset revision are in ../medagentbench_grpo_v1/download_manifest.json. Group labels are arbitrary local integers, including separate patient-less tasks. These files allow grade, cost and patient-disjoint split checks without publishing clinical content.
